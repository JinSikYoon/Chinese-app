바이두 번역 API 설정

중국 현지 사용 시 바이두 오픈 플랫폼(fanyi-api.baidu.com)에서 무료로 발급받은 APP ID와 Key를 등록하시면 가장 빠르고 정확하게 동작합니다.

아이폰 앱 설치 방법

  1. Safari 브라우저 하단 중앙의 공유 버튼()을 누릅니다.
  2. 메뉴를 내려 [홈 화면에 추가]를 선택합니다.
  3. 우측 상단 [추가]를 누르면 아이폰 바탕화면에 앱이 생성됩니다.
